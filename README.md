# TimeMachine ⏳

TimeMachine é um gerenciador de tarefas e acompanhamento de tempo focado em privacidade, simplicidade e portabilidade. Construído como um **PWA (Progressive Web App)** de arquivo único, ele funciona inteiramente no seu navegador, sem necessidade de servidores, bancos de dados externos ou conexão com a internet após o primeiro carregamento.

## ✨ Principais Características

-   **Privacidade em Primeiro Lugar**: Nenhum dado sai do seu dispositivo. Tudo é armazenado localmente via **IndexedDB**.
-   **PWA Instalável**: Instale no seu computador ou celular para usar como um aplicativo nativo.
-   **Modo Offline**: Funciona sem internet através de Service Workers.
-   **Zero Dependências**: Sem frameworks pesados ou bibliotecas externas. HTML, CSS e JavaScript puro.
-   **Design Moderno**: Interface responsiva com suporte a temas Claro, Escuro e Automático (vidromorfismo e animações fluidas).
-   **Anexos**: Suporte para anexar imagens diretamente nas tarefas.
-   **Exportação/Importação**: Faça backup total dos seus dados em formato JSON a qualquer momento.

## 🚀 Como Usar

Você pode usar o TimeMachine de duas formas:

1.  **Online**: Acesse através do [GitHub Pages](https://elmojunior.github.io/TimeMachine/timemachine.html).
2.  **Localmente**: Faça o download do arquivo `timemachine.html` e `sw.js` em uma pasta e abra o HTML no seu navegador.

### Instalação como App
No Google Chrome ou Edge, clique no ícone de instalação (⊕) na barra de endereços para instalar o TimeMachine no seu sistema.

## 🛠 Estrutura do Projeto

O projeto segue uma filosofia de "mínimo impacto":
-   `timemachine.html`: Contém toda a estrutura, estilos e lógica da aplicação.
-   `sw.js`: Service Worker para garantir o funcionamento offline.
